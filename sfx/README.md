# Sound effects (not included)

The skill and scripts expect sound effects in your project's `sfx/` folder. The originals came from [Pixabay](https://pixabay.com/sound-effects/). Their licence allows use inside videos but not redistributing the files on their own, so they are not part of this repo.

Download effects you like (Pixabay, Mixkit or your own library) and name them like this:

| File | Used for |
|---|---|
| `whoosh.mp3`, `whoosh-short.mp3`, `whoosh-cinematic.mp3` | B-roll entries, whip transitions |
| `impact-bass-1.mp3`, `impact-bass-2.mp3` | one or two peaks per video |
| `pop.mp3` | text appearing |
| `click.mp3`, `click-soft.mp3` | taps and UI zooms |
| `ping.mp3`, `chime.mp3`, `sparkle.mp3` | payoff, end card |
| `riser.mp3` | build-up into the payoff or a drop |
| `glitch-1.mp3` … `glitch-3.mp3` | optional accents |
| `typing.mp3` | typing on a phone keyboard |
| `sub-hit.wav` | a short, deep sub hit on reveals and logos (easy to make yourself from a decaying sine wave) |
