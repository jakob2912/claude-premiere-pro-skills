# Video project – instructions for Claude

Claude edits videos here in Adobe Premiere Pro through the Premiere MCP bridge and builds motion graphics with HyperFrames (HTML → MP4). Use the skill `reel-editor` for every cut and `critique-loop` before anything is handed over.

## Folders
- `raw/` – source material (never modify, never delete)
- `transcripts/` – Whisper output and cut lists
- `graphics/` – one folder per video (HyperFrames scenes, configs, STATUS.md)
- `exports/` – one folder per video: final file + cover on top, older versions in `versions/`
- `sfx/` – sound effects

## Rules
- Save the Premiere project before any bigger change and work in a NEW sequence; never overwrite existing sequences.
- No invented numbers, reviews or client statements in graphics; quote reviews verbatim only.
- Music loud only where nobody speaks.
